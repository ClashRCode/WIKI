Introduction

Le nombre d'or permettant d'exprimer le terme général des suites ( u n ) (un) vérifiant la récurrence linéaire définissant la suite de Fibonacci u n + 2 = u n + 1 + u n un+2 = un+1 + un, il a été proposé d'appeler nombres métalliques les nombres permettant d'exprimer, pour un nombre entier p, le terme général des suites ( u n , p ) un,p vérifiant la récurrence linéaire : u n + 2 , p = p u n + 1 , p + u n , p .

Par définition, le p-ième nombre métallique, noté φφ p p, est l'unique solution positive de l'équation caractéristique de la récurrence : x 2 = p x + 1 φ2 = pφ + 1.
